# BF6 Unreal SDK: High Poly

The planned high-detail add-on for [BF6 Unreal SDK](https://github.com/TabbedScamper/BF6_Unreal_SDK).

This is a community-made project. It is not affiliated with EA or DICE.

## What this will be

BF6 Unreal SDK builds Portal maps with the official SDK's low-poly proxy assets. This add-on layers the real thing on top:

- **Full-detail meshes**: the actual game models decoded straight from your Battlefield 6 install, overlaid on the low-poly build as a non-destructive preview
- **Materials and textures**: the real surface look, not proxy colors
- **Extended terrain**: the full map terrain and backdrop beyond the shipped low-poly proxy

Same idea as the high-poly preview plugin for the official Godot SDK, rebuilt for Unreal.

## Status

Not started yet. The base tool comes first. This repo goes live once BF6 Unreal SDK is stable.

## Requirements (planned)

- [BF6 Unreal SDK](https://github.com/TabbedScamper/BF6_Unreal_SDK)
- A legitimate installed copy of Battlefield 6 (the add-on reads assets from your own install)
